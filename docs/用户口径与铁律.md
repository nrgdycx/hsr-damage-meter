# 第三部分：铁律（踩过坑换来的，**必须遵守**）

## 3.1 归属规则（C 线 / T2 都用这套）

1. **归属依据 = 谁在攻击**（行动轴顶端那张卡 = 当前行动者）
2. **忆灵伤害算给召唤者**
3. **追击 / 插入终结技**：行动轴顶端会变成释放者的卡 → 按顶端卡归属
4. **附伤：倍率来自谁就算谁**（看技能介绍即可，**不靠数值反推**）
5. **敌人 / boss / 机制卡不计入我方伤害**
6. **阿哈时刻**：面具框占位，里面依次放欢愉技 → 需特判（框里头像是谁）
7. ⭐ **判不出来不猜** —— 低置信一律标 `待复核`，**宁可漏，不要错**

### 忆灵 → 召唤者映射（已入库）

| 忆灵 | 召唤者 | 出现条件（用户描述）|
|---|---|---|
| 德谬歌 | 昔涟 | 昔涟终结技后，**顶轴召唤**，行动完消失 |

## 3.2 与用户协作（**很实际，违反过**）

1. ⭐ **信息不足时，先把图摆给用户看，让用户用眼睛判断** ——
   不要自己闷头连试 N 轮再下结论。
   > 用户原话："不是你倒是把你觉得不对的给我看啊，你就是一直自己搞，
   > 你把对比图给我看我才知道问题在哪啊"
2. **不要用颜色编码传递信息**（深色底上绿字黄字用户分不出来）→ **只用文字标签**
3. **图片不要超过屏幕尺寸**，也不要超出画布
4. **不要让用户认孤立字形**（`0/8/9` 难分，会认错产生脏标签）；**整串数字用户一眼就能读对**
5. **报数字给用户看时不要带诱导**（曾加"应该是三位数"导致模型给出错误答案）
6. 需要用户看图时：存 PNG 后用 `cmd /c start "" "<绝对路径>"` 弹系统看图器
7. **用户读出来的数值是最可靠的标准答案**，优先用它建数据集

## 3.3 工程纪律

1. **评估必须用"留一帧/留出集"** —— 同一帧的字形不允许跨训练/测试集（否则准确率虚高）
2. **每个参数改动都要有客观指标验证**（识别率 / 分割正确帧数），不要凭感觉调
3. **多帧投票**是提高最终准确率的关键（单帧不可能 100%）
4. ✅ **改完必跑三条回归**：
   ```
   python eval_holdout.py                 → 逐字 29/29、整串 5/5
   python axis_actor.py --selftest        → 18 条真值帧 + 3 档缩放
   python -u events_v4.py --anchors  → 10 一致 / 0 不一致 / 8 正确弃权
   ```
5. ❌ **不要用 PowerShell 管道改源码**（会毁 UTF-8 中文 + 吃行首缩进，本项目栽过）
6. ✅ **移动/删除文件用 `git mv` / `git rm`**（保留历史）
7. **掩膜/分割的唯一实现是 `hud_glyphs.py`** —— 训练、离线、实时三方共用，
   **改一处即改全部**；改完必须回归
8. **`D:/project/btdsh/` 只读**，不要往里写文件

## 3.4 工具选型（**已排除的路，别重走**）

| 方案 | 为什么不行 |
|---|---|
| **在线 VLM 读数字** | 会凭空编造（实测造出 `123456789`、`1480776`）；且单次 2~4 秒，**违反实时硬需求** |
| **通用 OCR（RapidOCR）** | 把 `48076` 读成 `94087` |
| **伤害模型反查读数** | ⛔ D 线结论已被用户全盘否定 |
| **用官方素材自动建模板** | ❌ 实测不可行（穷尽 5061 个 PNG + 逐像素变换搜索，见 `任意队伍适配.md`）|
| **全图滑窗找行动轴** | ❌ 顶端槽是**固定**的，滑窗方案已被否 |
| **"优先采信位数更多的读数"** | ❌ 被杂散读数带偏（`1116982` 压过正确的 `721193`）→ 改"**位数取众数**" |

## 4.4 HUD 数字区的硬事实（已实测）

| 项 | 值 |
|---|---|
| 裁剪框（参考标定）| `CY0,CY1 = 260,340`，`CX0,CX1 = 2350,2876` |
| 对齐方式 | **右对齐**，最右数字右缘 ≈ **x2852** |
| 字距 | ≈ **34~37 px**（录屏2 中位 56px）；个位位置固定，位数增加向**左**延伸 |
| 两种字号 | 累积阶段小（字形高 ≈56~63px）、结算后大（≈73~74px）|
| 数字颜色 | **笔画核心是饱和黄**（`min(R,G)-B ≈ 95`，B≈150）；**外圈是淡黄辉光**（B≥185）|
| 掩膜（在用）| `(R>225)&(G>225)&(B>=185)&((R-B)>25)` —— 取**辉光层**（笔画连续，最利于分割）|
| 数字左侧细横线 | **UI 元素**，固定在 y≈**298~310**，会把开头数字"搭桥"粘成一块 → 必须挖空（`bar_rows`）|
| 行为 | 一次攻击结束后出现；**长攻击逐步累积**（最终值才是总伤）；昔涟大招期间**连续 ~16 秒无 HUD**（不是故障）|
