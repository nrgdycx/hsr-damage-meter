## 1. ⭐ 切分判据（`segment()`，全部有实测依据）

| # | 判据 | 依据（实测） |
|---|---|---|
| 1 | 读数空白 **≥ 1.5s** 断开 | 相邻间隔双峰分布（1.0s / 2.0s+）；`t=154→156` 隔 2.0s 是两次攻击 |
| 2 | 新读数 **< 段最大值 ×(1−20%)** 断开（重置）| `t=105 662096 → t=106 2809` |
| 3 | **归属者变化 + 数值没有继续增长** → 断开 | `t=154 324751`（顶端死龙/遐蝶）→ `t=156 866730`（顶端长夜/长夜月）是两次攻击；但 `t=156~163` 长夜链**读数一直涨**，不能按行动者切 |
| 4 | **召唤者 → 忆灵**、且数值没继续增长 → 断开 | 死龙/小伊卡是"主人行动后顶轴召唤"，与主人的行动**不是同一次** |
| 5 | 其余并入当前段，**段内取最大值** | — |

### ⚠️ 一条硬事实（**别搞反**）

**HUD「总伤害」是"一次攻击内累计"，不是整局累计** →
所以**段内取最大值**（实测 `121418→202126→4505→304505→304505→662096→2809`）。

> 曾被写成"整局累计"（D 线结论），**已被否定**。

## 2. ⭐ 归属规则（`attribute()`）

* **锚点** = 段内**数值最大**的那一帧；同值（数值停住）取**最早**那一帧。
  > 这一条是实跑改出来的：读数 `32209` 在 `t=221`（顶端昔涟）与 `t=222`（顶端长夜月）
  > 都存在，**取最晚 → 长夜月（错）**，取最早 → 昔涟（对，与真值一致）。
* 在锚点的 **`[-1.5s, +0.5s]`** 窗口里找已确认行动者，⚠️ **只能因果**：
  **优先取锚点之前最近的**，只有"之前一个都没有"才退到之后。（反例即上面那条 `t=221/222`）
* `owner` 直接取行动轴返回的 `owner`（**忆灵→召唤者已由行动轴侧映射好**）。
* `card_type`：

| card_type | 处理 |
|---|---|
| `enemy` | → `status=non_ally`（**不计入我方**，但保留在表里）|
| `aha` / `elation` | → `status=review`（要框内头像；见 [`附伤与开大踢轴.md`](附伤与开大踢轴.md)）|
| 判不出来 | → `status=review`，**不给归属也不猜** |

## 3. ⭐ 0.2s 密帧：真正的危险是**静默少读几位**

> ⛔ **先纠正一条被推翻的旧结论**
>
> 早期文档写"密帧读数变成**多一位前缀**、而且不带 `?`" —— **这是错的**。
> 它把"**修扫描器之前**的产物"当成了"当前识别层的行为"。
>
> | 旧说法 | 实测 |
> |---|---|
> | "密帧读数变成多一位前缀，不带 `?`" | ❌ 那些帧在当前口径下**全部带 `?`**（`?324751` / `?40185` / `?248752`）→ 本来就会被 `is_clean()` 整条丢掉 |
> | "122 个共同时刻里 5 个不同" | ❌ 用**当前**口径重扫：**共同整数秒帧 240 个读数完全相同、0 个不同** |
>
> ⚠️ **不要再引用 `out/frames_dense_C.csv` 当"密帧不可用"的证据** —— 它是修扫描器之前的。

**密帧真正的危险**：**静默少读几位（丢前导位）**，而且它**同时污染 1 fps 网格**。
后果不是"多一位"，而是**凭空造出假事件 + 数值偏低**。

**剔除规则**（每条都写清"不写它会错在哪"）：
* 读数带 `?` → 整条丢（低置信）
* 段宽 / 墨迹跨度异常 → 判可疑（实机曾把 `630911` 自信地读成 `1`）
* **段的时间跨度会"补回"被剔除的帧**（所以不能只看单帧）

## 5. 事件表字段与主表

`out/events_master.csv` 的统一列（详见 `out/README_事件表.md`）：

```
t_start, t_end, damage_max, owner, status, unit, card_type, marker,
grade, reject, attrib_owner, attrib_adopted, attrib_src, ...
```

`status` 取值：`ok`（可采纳） / `review`（待复核） / `non_ally`（敌方）。
**占比分母只含 `ok`** → **合计是下界**。

## 6. 接口

```python
import events_v4 as E          # 生产用（0.2s 密帧口径）
import events as EC         # 1 fps 基线口径

rows = E.load(...)                  # 读逐帧读数
segs = E.segment(rows)              # 切分
evs  = E.attribute(segs)            # 归属
```

命令行：
```powershell
python -u events_v4.py --anchors    # 锚点对账（10/0/8）
python -u events_v4.py --summary    # 按角色汇总
python -u events_v4.py --compare    # 与旧表对照
python -u events_v4.py --anchors --truth --compare --summary
python -m tools.events.diag_dense --frames out/frames_dense4.csv --grid out/frames_C.csv
```
