## ⚠️ 几条跨文档的铁律（详见 [`用户口径与铁律.md`](用户口径与铁律.md)）

1. ⭐ **判不出来不猜** —— 低置信一律标「待复核」，**宁可漏，不要错**
2. ⭐ **信息不足时，先把图摆给用户看**，不要自己闷头连试 N 轮
3. **归属靠规则，不靠数值反推**（D 线伤害模型结论已被用户全盘否定，已清理）
4. **不要用颜色编码传递信息**（只用文字标签）；图片不超过屏幕尺寸
5. **改完必跑三条回归**：
   ```
   python eval_holdout.py                 → 逐字 29/29、整串 5/5
   python axis_actor.py --selftest        → 18 条真值帧 + 3 档缩放
   python -u events_v4.py --anchors  → 10 一致 / 0 不一致 / 8 正确弃权
   ```
6. ❌ **不要用 PowerShell 管道改源码**（毁 UTF-8 中文 + 吃行首缩进）
7. ✅ **移动/删除用 `git mv` / `git rm`**（保留历史）
