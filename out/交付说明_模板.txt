========================================
 HSR 伤害统计（MVP）—— 使用说明
========================================

【怎么用】

  1. 双击本文件夹里的：HSR伤害统计.exe
  2. 弹出「HSR 伤害统计（MVP）」控制面板：
       · 悬浮窗位置：默认 40,40（屏幕左上角，可改）
       · 倒计时(秒)：点开始后过几秒才开始采集（留时间切回游戏）
       · 采集时长(秒)：3600 = 不停
  3. 点「▶ 开始统计」→ 倒计时结束后**立刻切回游戏**（游戏建议用「窗口化全屏」）
  4. 屏幕左上角会出现悬浮窗，实时显示各角色累计伤害
  5. 停止：面板上的「■ 停止」/ 关窗，或按热键 Ctrl+Alt+Q
     （悬浮窗是鼠标穿透的，点不到它）

  不需要装 Python，不需要命令行。整个文件夹一起拷走也能用
  （exe 同目录的 _internal 是它的资源，别删）。

【只在两个东西里】

  · HSR伤害统计.exe    ← 唯一入口，就双击它
  · 使用说明.txt       ← 本文件

  分发时把 解压出来的整个「HSR伤害统计」文件夹 打包发走即可。

【运行时想看点东西？】

  双击运行**没有**黑窗口（这是故意的）。运行输出都在同目录的：

      运行日志.txt

  实时事件、按角色累计、单帧耗时都写在这里（UTF-8，可直接用记事本打开）。
  想确认程序装好了，也可以在命令行里跑：

      HSR伤害统计.exe --selftest
      → 结果同样写进 运行日志.txt

【常见问题】

  · 双击没反应 / 一闪就没
      先把 exe 拖到「命令提示符」里回车，看报错；再看 运行日志.txt。
      个别杀软会拦截未签名程序，加白名单即可。

  · 悬浮窗看不见，但游戏正常
      游戏改「窗口化全屏 / 无边框」（独占全屏下桌面悬浮窗可能不显示）。

  · 数字一直是「待复核」
      多半不是这支队伍 / 分辨率变了；把 运行日志.txt 发来一起看。

  · 读数明显不对
      检查 exe 旁边**有没有多余的 out 文件夹**（旧的模型会被优先读）。
      ⚠️ 例外：`out\live_calib.json` 是本程序自己写的「本机 HUD 框标定」（很小，删掉无妨，
      删了下次开局会重新自动定位一次）。

  · 数字是「待复核 / 空的」
      先看 运行日志.txt 里的「HUD 读数可靠性」段：它会列出
      画面里有黄墨迹的帧占比、读到完整数字的帧占比、框来源（ink/model/calib）、重定位次数。
      如果框来源一直是 model（没切到 ink），把日志发来一起看。

【第一次用会自己标定】

  · 第一次跑：开始时用兜底框，**画面上一出现伤害数字就自动切到正确的框**（日志里能看到
    「✓ 重定位 HUD → …」），并把这一对 (框, 金线行带) 记进 `out\live_calib.json`。
  · 之后每次跑：**进战前启动也能直接读对**（用上次的标定；分辨率变了会自动作废重来）。

【悬浮窗与抓屏的关系（重要）】

  · 本程序靠"读屏幕"工作，而悬浮窗本身也是一个窗口。**如果它压住游戏左上角的行动轴，
    抓屏就会把它自己也拍进去 → 认不出"当前是谁在打" → 合计一直是 0 / 待复核。**
  · 所以悬浮窗被设成"**对抓屏隐身**"：你在屏幕上照常看得见，但抓屏 API 拍不到它
    （启动日志里会写「悬浮窗：对抓屏不可见(capture-hidden) = 是 ✓」）。
  · 副作用：**你自己用截图/录屏工具**时，画面里也不会有这个悬浮窗（这是它生效的表现）。
  · 万一某台机器上设不上（日志会写"**否** ✗"），用 `--pos` 把窗口挪开即可，
    例如：`HSR伤害统计.exe --pos 1500,1450`。

【已知限制（诚实清单）】

  · 只支持录屏1 那支队伍（遐蝶/长夜月/风堇/昔涟），录屏2 的队伍覆盖不全
  · 事件定稿有约 2.4 秒延迟（最后几秒的数字会稍后才进合计）
  · 「每行动值伤害」目前恒显示 —
  · 多分辨率只做过离线缩放自检，未在真机逐档实测
  · 游戏有时把伤害显示成**更大的字号**（不带「总伤害」标签）：这种帧**读不出来**
    （宁可漏，不要错）—— 那些帧的数字不会进统计，但不影响其它帧
  · 退出热键 `Ctrl+Alt+Q` 的自动化验证做不了（本开发环境的沙箱禁止注入/读取全局按键）；
    它已改为**每帧直接查按键状态**。若实在不灵，用控制面板上的「■ 停止」。
